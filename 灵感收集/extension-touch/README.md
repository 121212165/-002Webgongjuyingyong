# 灵感挖掘机 - 触摸屏版使用说明

## 概述

灵感挖掘机触摸屏版是专为触摸屏设备（如平板电脑、手机）优化的思维导图工具。除了保留核心的思维导图功能外，还针对触摸操作进行了深度优化，支持多种触摸手势和便捷的交互方式。

## 主要特性

- **触摸优先设计**：大按钮、宽松间距，专为手指操作优化
- **长按菜单**：在节点上长按即可弹出操作菜单
- **手势支持**：支持双指缩放、双指平移、拖拽等手势
- **AI 集成**：支持 GLM-4.7 AI 对话，可通过自然语言创建和编辑思维导图
- **响应式布局**：适配各种屏幕尺寸

## 基本操作

### 创建节点

**方法一：使用工具栏**
1. 点击底部工具栏的 **"新建根节点"** 按钮创建根节点
2. 选中一个节点后，点击 **"添加子节点"** 按钮创建子节点

**方法二：使用菜单**
1. 在画布空白处长按，弹出快捷菜单
2. 选择 **"新建根节点"**

**方法三：AI 对话**
1. 点击底部 **"AI 对话"** 按钮
2. 输入如"创建一个关于项目规划的思维导图"
3. AI 会自动创建节点和连接

### 选择节点

- **点击**：单击节点可选中节点（显示蓝色边框）
- **拖拽**：按住节点可拖拽移动位置

### 编辑节点

**方法一：工具栏**
1. 选中节点
2. 点击底部工具栏的 **"编辑"** 按钮
3. 输入新内容后确认

**方法二：长按菜单**
1. 在节点上长按
2. 在弹出菜单中选择 **"编辑"**

### 删除节点

1. 选中节点
2. 点击底部工具栏的 **"删除"** 按钮
3. 确认删除

或使用长按菜单中的 **"删除"** 选项

### 连接节点

1. 在节点 A 上长按
2. 选择 **"连接节点"**
3. 点击节点 B 完成连接

## 触摸手势

### 单指操作

| 手势 | 功能 |
|------|------|
| 点击 | 选中节点 |
| 长按 | 弹出操作菜单 |
| 拖拽 | 移动节点位置 |
| 滑动 | 平移画布（在空白区域） |

### 双指操作

| 手势 | 功能 |
|------|------|
| 双指捏合 | 缩放画布 |
| 双指平移 | 同时平移画布 |

### 快捷操作

- **快速点击 5 次**：重置视图到中心位置

## 视图控制

在画布右上角有一组视图控制按钮：

- **放大**：点击放大视图
- **缩小**：点击缩小视图
- **重置视图**：点击恢复到默认缩放级别
- **居中**：点击将思维导图居中显示

也可以直接使用双指捏合手势来缩放。

## AI 智能对话

### 开启 AI 对话

点击底部工具栏的 **"AI 对话"** 按钮，打开 AI 对话面板。

### 可用的 AI 工具

AI 可以执行以下操作：

| 工具名称 | 功能 | 示例指令 |
|----------|------|----------|
| create_node | 创建节点 | "创建一个关于时间管理的新节点" |
| connect_nodes | 连接节点 | "连接'目标'和'计划'两个节点" |
| update_node | 更新节点 | "将'节点A'改名为'新名称'" |
| delete_node | 删除节点 | "删除'临时节点'" |
| get_nodes | 获取节点信息 | "现在有哪些节点？" |

### 使用示例

```
用户：帮我创建一个项目规划的思维导图

AI：[创建根节点"项目规划"]
好的！我已经为您创建了根节点"项目规划"。您想要添加哪些子节点呢？

用户：添加"目标"、"时间线"、"资源"三个子节点

AI：[创建节点"目标"]
[创建节点"时间线"]
[创建节点"资源"]
已添加三个子节点。

用户：在"目标"下添加"短期目标"和"长期目标"

AI：[创建节点"短期目标"作为"目标"的子节点]
[创建节点"长期目标"作为"目标"的子节点]
已添加两个子节点。
```

## 设置选项

点击底部导航栏的 **"设置"** 按钮可进入设置页面。

### AI 配置

- **API Key**：输入您的 GLM-4.7 API Key
- **API 地址**：API 接口地址
- **模型名称**：默认为 glm-4.7

### 触摸设置

- **长按显示菜单**：开启/关闭长按弹出菜单功能
- **双指缩放**：开启/关闭双指捏合缩放手势
- **振动反馈**：开启/关闭操作时的振动反馈（需要设备支持）

### 数据管理

- **导出数据**：将所有数据导出为 JSON 文件
- **导入数据**：从 JSON 文件导入数据
- **清空所有数据**：删除所有本地存储的数据

## 数据导出与导入

### 导出数据

1. 进入 **设置** 页面
2. 点击 **"导出数据"** 按钮
3. 数据将下载为 JSON 文件

### 导入数据

1. 进入 **设置** 页面
2. 点击 **"导入数据"** 按钮
3. 选择之前导出的 JSON 文件

## 常见问题

### 触摸无响应怎么办？

1. 确保触摸区域在画布范围内
2. 尝试重载插件
3. 检查是否开启了触摸功能（设置 > 触摸设置）

### 长按菜单不弹出怎么办？

1. 确认长按时间足够（默认 600 毫秒）
2. 检查是否启用了长按菜单功能（设置 > 触摸设置 > 长按显示菜单）
3. 尝试重启插件

### AI 功能无法使用怎么办？

1. 检查 API Key 是否正确配置
2. 确认 API 地址和模型名称正确
3. 测试网络连接

### 如何重置视图？

- 点击右上角的 **"居中"** 按钮
- 或快速点击屏幕 5 次

## 快捷键（外接键盘时）

| 按键 | 功能 |
|------|------|
| Delete | 删除选中的节点 |
| Escape | 取消操作 / 关闭面板 |
| +/- | 缩放视图 |
| 方向键 | 微调选中节点位置 |

## 注意事项

1. **数据保存**：数据会自动保存到本地存储
2. **节点数量**：建议节点数量不超过 100 个以保持流畅性能
3. **API 使用**：AI 功能需要有效的 API Key，会产生相应的 API 调用费用
4. **浏览器兼容性**：建议使用 Chrome 80+ 或 Edge 80+ 浏览器
