# AI 智能对话模式使用说明

## 概述

灵感挖掘机支持 AI 智能对话功能，AI 不仅能回答您的问题，还能通过工具调用直接操作思维导图，包括创建节点、连接节点、更新内容和删除节点等。

## 使用方法

### 1. 开启功能
在插件主界面中找到 AI 对话区域。

### 2. 与 AI 对话
在对话框中输入您的需求，AI 会自动分析并调用相应的工具来操作思维导图。

### 3. 可用的 AI 工具
AI 可以执行以下操作：

#### 创建节点
- **指令示例**：
  - "创建一个关于'项目规划'的节点"
  - "在'目标'节点下添加一个新节点，内容是'第一步：需求分析'"
  - "创建一个新节点，位置在(200, 300)"

- **功能说明**：
  - AI 会根据当前思维导图的结构自动安排新节点的位置
  - 如果指定了父节点，AI 会自动建立连接

#### 连接节点
- **指令示例**：
  - "连接'需求分析'和'功能设计'两个节点"
  - "建立从'节点A'到'节点B'的连线"

- **功能说明**：
  - AI 会在两个节点之间创建连接线
  - 支持双向连接

#### 更新节点
- **指令示例**：
  - "将'节点名称'改名为'新名称'"
  - "更新'需求分析'节点的内容为'详细分析用户需求'"

- **功能说明**：
  - 可以修改节点的文本内容
  - AI 会找到对应的节点并更新

#### 删除节点
- **指令示例**：
  - "删除'临时节点'"
  - "移除'测试节点'及其所有子节点"

- **功能说明**：
  - 删除节点时，会同时删除与之相关的连接线
  - 如果节点有子节点，会询问是否级联删除

#### 获取节点信息
- **指令示例**：
  - "查看当前所有节点"
  - "显示思维导图的结构"
  - "列出所有节点及其关系"

- **功能说明**：
  - AI 会返回当前思维导图的所有节点信息
  - 展示节点之间的层级关系

## 使用技巧

### 1. 自然语言交互
可以直接用自然语言描述需求，AI 会理解并执行：
```
❌ "调用create_node工具，参数text='新想法'，parent_id=1"
✅ "在根节点下添加一个新想法"
```

### 2. 批量操作
可以一次性提出多个需求：
```
"创建一个'时间管理'节点，然后在下面添加'番茄工作法'和'四象限法则'两个子节点"
```

### 3. 询问状态
可以随时询问当前思维导图的状态：
```
"现在思维导图里有哪些节点？"
```

### 4. 设计建议
可以让 AI 给出建议和优化：
```
"帮我看看这个思维导图的结构是否合理？"
"有什么可以补充的节点建议？"
```

## 注意事项

1. **节点命名**：尽量使用有意义的名称，这样 AI 能更准确地识别您想操作的节点

2. **位置说明**：如果不指定位置，AI 会自动计算合适的位置

3. **连接说明**：连接节点时，确保两个节点都存在

4. **删除谨慎**：删除操作会同时移除相关的连接线，请谨慎操作

## 示例对话

### 示例 1：创建基础结构
```
用户：帮我创建一个项目规划的思维导图

AI：[创建根节点"项目规划"]

用户：添加子节点"目标"、"时间线"、"资源"

AI：[创建三个子节点并建立连接]

用户：在"目标"下添加"短期目标"和"长期目标"

AI：[在"目标"节点下创建两个子节点]
```

### 示例 2：整理思路
```
用户：我现在思维导图很乱，帮我整理一下

AI：[获取所有节点信息]
让我先看看当前的结构... 建议将"测试"节点移动到"开发"节点下，使其成为子节点。

用户：好的，按你说的做

AI：[更新节点关系]
```

### 示例 3：迭代优化
```
用户：我觉得"资源"这个节点内容太简单了，帮我扩展一下

AI：将"资源"更新为"资源分配：人力、资金、设备"

用户：再添加一些具体的资源类型

AI：[创建子节点：人力、资金、设备]
```

## 故障排除

### AI 无法识别节点
- **问题**：AI 报告找不到您指定的节点
- **解决**：使用完整的节点名称，或先让 AI 列出所有节点后再操作

### 工具调用失败
- **问题**：AI 尝试调用工具但失败
- **解决**：
  - 检查节点是否存在
  - 确认参数格式正确
  - 尝试简化指令

### 位置冲突
- **问题**：节点位置重叠
- **解决**：AI 会自动重新计算位置，您也可以手动调整

## 技术细节

- **AI 模型**：GLM-4.7
- **工具调用方式**：Function Calling
- **API 配置**：在选项页面中配置 API Key 和接口地址
